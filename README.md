## ✨ Features

- **Multi-session management** - Handle multiple reverse shells simultaneously
- **Cross-platform** - Works on Windows, Linux, and macOS
- **Pure Python** - No external dependencies, uses only standard library
- **Interactive console** - Intuitive CLI with command history
- **Payload generation** - Built-in payload templates for different targets
- **Session persistence** - Automatic reconnection handling
- **Lightweight** - Single file, < 150 lines of code
